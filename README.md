# 🎓 Student Registration System

A responsive web application built using **HTML, Tailwind CSS, and JavaScript** that allows users to efficiently manage student records with full CRUD operations and persistent storage.

---

## 🚀 Live Features

✨ Add new student records
✏️ Edit existing student details
🗑️ Delete student entries
📋 View all registered students in a table
💾 Data stored using **localStorage** (no data loss on refresh)
📱 Fully responsive (Mobile / Tablet / Desktop)
📊 Dynamic scrollbar for large datasets
📂 Clean and user-friendly UI

---

## 📸 Project Overview

The **Student Registration System** is designed to simplify the process of managing student information digitally. Users can easily register students, update their details, and remove records when needed. The system ensures data accuracy through validation and maintains persistence using browser storage.

## 📋 Functionalities

### ✅ Add Student

* Input fields for Name, ID, Age, Email, Contact
* Validations applied before submission

### ✅ View Students

* Data displayed in structured table format
* Serial number for each entry

### ✅ Edit Student

* Popup-based editing
* Updates reflected instantly

### ✅ Delete Student

* Removes selected record
* Table updates dynamically

---

## 🔐 Validation Rules

* 🔤 Name → Only alphabets allowed
* 🔢 Student ID → Numbers only
* 📧 Email → Must be valid format
* 📱 Contact → Minimum 10 digits
* 🚫 Empty fields not allowed
* ⚠️ Duplicate IDs are prevented

---

## 📱 Responsive Design

The application is fully responsive across:

* 📱 Mobile (≤ 640px)
* 📟 Tablet (641px–1024px)
* 💻 Desktop (≥ 1025px)

Includes a **mobile navigation toggle menu** for better usability.
